# Day-1-Hitman_Hafizh-Mulya-Hernawan
Repository ini digunakan untuk mengumpulkan dokumentasi kegiatan seperti materi yang disampaikan, catatan pembelajaran, selama workshop berlangsung.

Misi ini dilaksanakan dengan tujuan sebagai berikut: memperkenalkan peserta pada platform GitHub sebagai sarana penyimpanan dan pengelolaan dokumentasi secara daring, melatih peserta membuat dan mengelola repository dengan visibilitas Public, membiasakan peserta mendokumentasikan materi dan kegiatan selama workshop berlangsung, meningkatkan kemampuan peserta dalam menyusun catatan dan mengelola file secara terstruktur, melatih peserta menggunakan file README.md sebagai dokumentasi utama repository.

Dokumentasi kegiatan workshop:

a. Rangkuman materi yang disampaikan selama workshop:
- Konteks adalah kunci untuk memberikan prompt ke AI.
- Prompt dengan konteks akan mendapatkan hasil yang lebih baik daripada prompt tanpa konteks atau alur yang sesuai.
- Prompt tanpa konteks akan menghasilkan output yang tak sesuai harapan.
- Good prompt structure: role, task, context, format.
- Prompt adalah hasil dari iterasi, artinya hasilnya tak akan selalu sesuai dengan apa yang kita mau. Untuk mendapatkan hasil yang kita mau dari prompt yang kita berikan, lakukan iterasi secara berkala.
- AI tidak menyimpan riwayat percakapan kita.
- Keuntungan prompt engineering: meningkatkan peforma AI model, mengurangi bias dan respon yang offensive, meningkatkan kontrol dan predictability, memberikan pengalaman yg lebih baik.
- Git adalah version control system-yang melacak siapa, kapan, dan apa saja yang sudah dirubah dalam suatu file. Git diciptakan oleh Linus Torvalds pada tahun 2005.
- 3 working area git: working directory, staging area, git directory (repository).

b. Poin-poin penting atau pengetahuan baru yang dipelajari saat workshop:
- Konteks adalah faktor penentu kualitas output.
- Struktur prompt yang baik: Role, Task, Context, Format.
- Prompting adalah proses iteratif.
- AI tidak punya kemampuan bawaan untuk mengingat percakapan sebelumnya.
- Manfaat prompt engineering: meningkatkan peforma model, mengurangi bias dan respons yang offensive, meningkatkan kontrol dan prediktabilitas hasil, memberikan pengalaman pengguna yang lebih baik.
- Git adalah version control system.
- Tiga area kerja Git: working directory, staging area, git directory (repository).

c. Pendapat pribadi tentang Day 1 Proyek Workshop
- Menurut saya, materi ini sangat relevan karena banyak orang mengganggap AI "kurang pintar" padahal masalahnya ada di prompt yang kurang jelas. Struktur Role, Task, Context, Format memudahkan saya menyusun perintah dengan lebih terarah, dan saya juga jadi sadar bahwa hasil AI sangat bergantung pada kualitas instruksi dari penggunanya.
